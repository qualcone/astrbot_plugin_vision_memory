# astrbot_plugin_vision_memory

让文字模型（如 DeepSeek）的机器人能"看图"，并记住联网确认过的角色。插件不保存任何 API Key，所有模型调用都走 AstrBot 已配置的提供商。

## 功能
1. **图转文**：收到图片时，用你指定的识图提供商生成描述，替换原图后交给主模型。
2. **行为指引**：自动追加一段提示词（不覆盖人设），让模型遇到不熟悉的角色时先查记忆、再联网搜索、最后保存。
3. **长期记忆**：提供两个 LLM 工具 `remember_character` / `recall_character`；后续消息中提到已记住的名字时，自动把相关条目（默认最多 3 条）附加给模型。

## 使用前提
- 在 AstrBot 里先配好一个能识图的提供商（如 Gemini），再到本插件配置里选它。
- 如果同时设置了 AstrBot 内置的"默认图片转述模型"，请清空它，避免重复转述。
- 联网搜索使用 AstrBot 内置的 Web Search（配置 → AI → 能力，需在机器人实际使用的配置文件里开启），且主模型必须支持 Function Calling。本插件的记忆工具同样依赖 Function Calling。

## 指令
- `/vmem list` 列出记忆
- `/vmem del <名称>` 删除一条（管理员）

## 说明
- 记忆全局共享（不分会话/用户），存在插件 KV 存储中。
- 图片会被发送到你选的识图提供商；免费层的数据可能被服务商用于改进产品，请自行评估。
- 记忆内容由模型写入，可能出错，发现错误请用 `/vmem del` 删除。
